# NassAI-Praxis in Five Minutes

1. Clone the repository or start from the [`template/`](template/) directory.
2. Install the integration for your agent using [`INSTALL.md`](INSTALL.md).
3. Start a session and ask: **“Read my Praxis context and tell me the active conventions.”**
4. Complete one small task, then ask the agent to evaluate its work.
5. Review `memory/working/current.md` and `evolve/refine/patterns.md`; all memory writes must pass the security scan.

For deeper guidance, read [`docs/PROJECT_OVERVIEW.md`](docs/PROJECT_OVERVIEW.md), [`docs/AGENT_TESTING.md`](docs/AGENT_TESTING.md), [`docs/VALIDATION_INDEX.md`](docs/VALIDATION_INDEX.md), [`FAQ.md`](FAQ.md), and [`CONTRIBUTING.md`](CONTRIBUTING.md).
