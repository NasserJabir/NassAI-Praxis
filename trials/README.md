# Real-Project Trial Records

This directory contains Markdown records for a real project trial. It is separate from Praxis Core: it records evidence about Praxis without becoming a second runtime or knowledge store.

## Start a Trial

1. Choose and freeze a real project commit.
2. Create `trials/<trial-id>/sessions/`.
3. Copy `templates/session-observation.md` once per session.
4. Record what was available, discovered, reused, forgotten, wrong, created, and reused later.
5. Write the final comparison in `benchmarks/benchmark-002/` without inventing values.

Do not edit persona, skill, or core architecture files during the trial. Any improvement suggestion belongs in the normal proposal and review flow after the trial.
