# Test Experience Log

## Format
Each entry should include:
- **Date**: When the testing was conducted
- **Subject**: What was tested
- **Approach**: Testing methodology used
- **Outcome**: Results achieved
- **Quality**: Self-assessment (1-5)
- **Lessons**: What was learned
