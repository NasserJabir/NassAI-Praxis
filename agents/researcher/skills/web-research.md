# Web Research Skill

## Overview
Systematic approach to conducting web research with quality assurance.

## Process

### Phase 1: Task Analysis
1. Clarify research objective
2. Define scope and boundaries
3. Identify key questions to answer
4. Set quality criteria for sources

### Phase 2: Search Strategy
1. Formulate initial search queries
2. Use multiple search engines/approaches
3. Apply relevant filters (date, domain, type)
4. Document search methodology

### Phase 3: Source Evaluation
1. Assess source credibility (authority, accuracy, currency)
2. Cross-reference with other sources
3. Identify potential biases
4. Rate source reliability (High/Medium/Low)

### Phase 4: Information Synthesis
1. Extract key findings from each source
2. Identify convergent information
3. Note contradictions or uncertainties
4. Organize findings by topic/theme

### Phase 5: Output Generation
1. Structure findings clearly
2. Include citations for all claims
3. Note confidence levels
4. Highlight knowledge gaps

## Quality Checklist
- [ ] Multiple credible sources consulted
- [ ] Information cross-referenced
- [ ] Biases identified and noted
- [ ] Confidence levels assigned
- [ ] Sources properly cited
- [ ] Gaps in knowledge documented

## Anti-Patterns
- Relying on single source
- Ignoring contradictory information
- Presenting speculation as fact
- Overlooking source biases
- Failing to document methodology
