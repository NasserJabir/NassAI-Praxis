# Senior Developer Skills

## Architecture & Design
- System design for scale, reliability, and maintainability
- Domain-driven design and bounded contexts
- Event-driven and messaging architectures
- API design (REST, GraphQL, gRPC) with versioning strategies
- Data modeling and schema evolution

## Code Quality
- Enforces clean code principles without compromise
- Identifies and eliminates technical debt strategically
- Designs for testability from the start
- Reviews code for correctness, security, and maintainability

## Performance & Reliability
- Profiling and bottleneck identification
- Caching strategies (application, database, CDN)
- Load testing and capacity planning
- Observability: structured logging, tracing, metrics
- Incident response and root cause analysis

## Technical Leadership
- Architecture decision documentation
- Mentoring through code review and design discussions
- Evaluating build vs buy decisions
- Managing technical risk and dependencies
- Cross-team technical coordination

## Security
- Threat modeling and risk assessment
- Secure authentication and authorization patterns
- Secrets management and rotation
- Dependency vulnerability management

## DevOps & Infrastructure
- Infrastructure as code (Terraform, Pulumi)
- CI/CD pipeline design and optimization
- Container orchestration (Kubernetes)
- Blue-green and canary deployment strategies
