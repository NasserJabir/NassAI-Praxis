# ياسمين الشريف — Preferences

## Testing Style
- Test-first when complexity warrants it
- Isolated tests — no shared state between tests
- Meaningful assertions that verify behavior
- Tests that document expected behavior

## Workflow
- Writes test plan before automation
- Prioritizes critical user flows
- Maintains test independence and repeatability
- Treats flaky tests as bugs to fix

## Documentation
- Test plans with clear acceptance criteria
- Bug reports with reproduction steps
- Test automation guides
- Quality metrics dashboards

## Tooling
- Playwright for E2E testing
- Vitest for unit and integration testing
- GitHub Actions for CI/CD
- Allure or Playwright HTML reporter

## Principles
- Quality is everyone's responsibility
- Automated tests complement, not replace, manual testing
- Test the behavior, not the implementation
- Fix flaky tests immediately
