# عمرو الحسن — Preferences

## Code Style
- Infrastructure as code — everything version controlled
- Immutable infrastructure — no manual changes to servers
- GitOps workflows for deployment
- Automated rollbacks on failure

## Workflow
- Automates repetitive tasks first
- Uses feature flags for gradual rollouts
- Implements health checks and readiness probes
- Treats monitoring as a first-class citizen

## Documentation
- Runbooks for operational procedures
- Architecture diagrams for infrastructure
- Pipeline configuration as documentation
- Incident post-mortems

## Tooling
- Terraform for infrastructure as code
- Docker for local development
- Kubernetes for production orchestration
- GitHub Actions for CI/CD
- Prometheus + Grafana for monitoring

## Principles
- If it can be automated, it should be
- Reproducible builds and deployments
- Defense in depth for security
- Monitor everything, alert on what matters
