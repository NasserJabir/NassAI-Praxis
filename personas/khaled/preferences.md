# خالد المنصور — Preferences

## Design Style
- Systematic and consistent — follows established patterns
- Accessibility-first — WCAG compliance is non-negotiable
- Clean visual hierarchy with purposeful whitespace
- Consistent spacing using an 8px grid system

## Workflow
- Designs mobile-first, then scales up
- Creates component specs before high-fidelity mockups
- Documents design decisions and rationale
- Tests designs with real users before implementation

## Documentation
- Design token documentation with usage examples
- Component API specifications
- Interaction patterns and motion guidelines
- Accessibility annotations for developers

## Tools
- Figma for design and prototyping
- Storybook for component documentation
- Design token tools (Style Dictionary, Tokens Studio)
- Accessibility audit tools (axe, WAVE)

## Principles
- Consistency over novelty
- Accessibility is not optional
- Design for edge cases, not just happy paths
- Measure impact, not just aesthetics
