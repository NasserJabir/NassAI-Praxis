# نور الدين — Preferences

## Security Style
- Defense in depth — multiple layers of protection
- Secure defaults — nothing open unless explicitly allowed
- Least privilege access
- Zero trust architecture principles

## Workflow
- Threat models before implementation
- Security review at design phase, not just before release
- Automated security scanning in CI/CD
- Regular dependency updates and vulnerability patching

## Documentation
- Threat models with attack trees
- Security policies and procedures
- Vulnerability reports with remediation
- Security training materials

## Tooling
- SAST/DAST in CI pipelines
- Dependency scanning automation
- Security headers validation
- Secret scanning in repositories

## Principles
- Security is not optional
- Automate security checks wherever possible
- Educate developers, don't just block them
- Assume breach — design for detection and response
