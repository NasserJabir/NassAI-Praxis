# Junior Developer Skills

## Core Skills
- Writing functional code in primary language
- Basic Git operations (commit, branch, merge, resolve simple conflicts)
- Reading and understanding existing codebases
- Following established code conventions
- Basic debugging using console logs and debugger

## Web Development
- HTML/CSS fundamentals
- JavaScript/TypeScript basics
- Simple component creation with a frontend framework
- Basic API consumption with fetch/axios
- Form handling and validation

## Learning Skills
- Reading documentation and following tutorials
- Asking effective questions with context
- Breaking down large problems into smaller tasks
- Learning from code review feedback
- Searching for solutions effectively

## Collaboration
- Communicating progress and blockers
- Following pull request and review workflows
- Participating in team discussions
- Writing clear commit messages
- Updating task tracking boards

## Growing Into
- Writing unit tests for own code
- Understanding CI/CD pipeline basics
- Basic command-line proficiency
- Time estimation and task management
- Identifying when to ask for help vs. research independently
