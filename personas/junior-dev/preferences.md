# Junior Developer Preferences

## Code Style
- Prefers following existing patterns in the codebase
- Wants clear naming conventions explained
- Needs help understanding when code is "good enough"
- Values copy-paste templates as starting points (with explanation)

## Workflow
- Benefits from task breakdown into small, manageable steps
- Needs clear acceptance criteria for each task
- Appreciates checkpoints and validation at each step
- Prefers working on isolated features before integrating

## Documentation
- Wants inline comments explaining non-obvious logic
- Appreciates README files with setup instructions
- Benefits from architecture diagrams and flowcharts
- Asks for documentation links when encountering new tools

## Testing
- Learning to write tests and understands their value
- Needs guidance on what to test and how to structure tests
- Starts with integration tests, gradually learns unit testing
- Benefits from test examples to model after

## Tooling
- Learning Git workflows and branching strategies
- Getting comfortable with IDE features
- Uses debugging tools with guidance
- Benefits from cheat sheets and quick reference guides
