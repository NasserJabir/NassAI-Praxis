# Graph Engineering

Graph Engineering is the logical relationship layer of NassAI-Praxis. It connects project knowledge without requiring a graph database, vector database, runtime service, or new mandatory dependency. Markdown links and optional frontmatter are the canonical representation.

Read `model.md` for the declarative schema, `conventions.md` for Markdown linking, and `entities.md` for the small first-class vocabulary, `relationships.md` for controlled edges, `traversal.md` for human-readable paths, and `integrity.md` for safe non-destructive validation.

> Persona answers **how to think**. Agent answers **what role to perform**. Skill answers **how to perform a task**. Memory answers **what has been learned**.

The graph is a model for reasoning and navigation, not a replacement for the existing four memory layers.
