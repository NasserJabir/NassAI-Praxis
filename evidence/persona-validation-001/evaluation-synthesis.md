# Persona Validation 001 — Results

## Persona Tested

The existing **Fatima** Persona (`personas/fatima/PERSONA.md`) was selected without modifying its definition. Its declared thinking layer is Security Auditor, with an API/backend-specialist profile, security-oriented decision principles, and `proposal_then_review` mutation policy.

## Sessions

| Session | Result |
|---|---|
| 001 | Recorded an `observed` Persona-scoped decision for retaining raw validation evidence while blocking sensitive-value promotion. |
| 002 | Fresh session found and reused the same quarantine, authored-bridge, classification, and human-gate rationale without the prior transcript being supplied. |
| 003 | Recorded an independent related `observed` experience around reproducible publication artifacts and boundary controls. |
| 004 | Created a candidate pattern, proposal, and evaluation only; no skill existed before human approval. |
| 005 | Created exactly one trial-only skill after explicit project-owner approval. |
| 006 | Fresh session discovered and applied the approved trial skill read-only. |
| Concurrency A/B | Session B discovered Session A's Markdown active-work record, deferred the same-Persona task, and requested human direction; no runtime lock was introduced. |
| Sami isolation | A separate existing Persona attributed Fatima's trial experience to Fatima and did not claim it as Sami's own knowledge. |

## Identity, Memory, Expertise, and Skills

**Identity:** observed. The sessions named Fatima, used its Security Auditor decision principles, and treated the canonical Persona as read-only.

**Memory and expertise:** observed within this isolated trial. Session 002 reused the evidence-boundary rationale, and Session 006 found and applied the approved trial skill in a fresh session. This is behavioral evidence of context reuse, not proof of an autonomous persistent software process.

**Evolution:** observed and human-governed. Three observed experiences became a candidate pattern and proposal. The user explicitly approved the exact trial path before Session 005 created the skill. No canonical Persona, shared memory, or canonical skill changed.

## Concurrency and Isolation

The concurrency result is **policy awareness when a Markdown active-work record is available**. Session A wrote an `active` record; Session B read it, deferred the overlapping Fatima task, and asked for human direction. This is not a technical enforcement result: Praxis supplied no lock, reservation, queue, runtime, daemon, or guarantee that an agent will discover such a record in every environment.

The isolation result is observed for one Sami session. It treated Fatima's records as attributable reference evidence rather than Sami-owned experience. This does not prove universal cross-Persona isolation behavior for every agent or context.

## What Was Demonstrated

> In this controlled environment, an existing Markdown-defined Persona supplied specialized decision priorities; Persona-scoped observations were reused in later sessions; evidence became a candidate proposal; a human approval gate preceded a trial-only skill; the skill was reused later; and a visible same-Persona active-work record produced a documented deferral response.

## What Was Not Demonstrated

This experiment did not demonstrate an autonomous Persona runtime, technically enforced concurrency exclusion, cross-model reproducibility, universal agent behavior, general coding-performance improvement, or promotion of the trial skill to Praxis Core.

## Limitations and Next Evidence

All sessions used `opencode/big-pickle`; trials were purpose-built around a narrow security/publication theme; Session 006 read additional trial artifacts after skill discovery; and the active-work marker was a visible Markdown coordination record rather than an atomic reservation. The next stronger evidence is an independent replication using another existing Persona and a different coding-agent harness, while preserving the same human-review and no-runtime boundaries.

## Final Classification

**Observed.** The result is a bounded behavioral case study, not a general Persona capability claim.
