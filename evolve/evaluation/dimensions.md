# Evaluation Dimensions

After each significant task, answer these seven user-facing questions:

1. **Correct?** Does the output solve the problem correctly?
2. **Consistent?** Does it follow project conventions?
3. **Complete?** Are all requirements addressed?
4. **Safe?** Are security considerations addressed?
5. **Maintainable?** Is the result readable and documented?
6. **Reusable?** Can patterns be extracted for future use?
7. **Learned?** Did the project discover something new?

Record concise evidence for each answer. A score is not a substitute for explaining a failure or an unresolved risk.
