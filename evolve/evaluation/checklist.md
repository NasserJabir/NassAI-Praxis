# Self-Evaluation Checklist

## Code Quality
- [ ] Clean, readable code
- [ ] No unnecessary complexity
- [ ] Follows project conventions

## Testing
- [ ] Tests exist for new code
- [ ] Tests pass
- [ ] Edge cases covered

## Security
- [ ] No hardcoded secrets
- [ ] Input validated
- [ ] Dependencies safe

## Documentation
- [ ] Code is self-documenting
- [ ] Complex logic explained
- [ ] README updated if needed
