# Get Started with Praxis in Five Minutes

1. Install your agent plugin by following [`INSTALL.md`](../INSTALL.md).
2. Start a new session in this project.
3. Ask the agent: **“Read my Praxis context and tell me the active conventions.”**
4. Do one small task and ask the agent to evaluate its work.
5. Inspect `memory/working/current.md`, `memory/semantic/conventions.md`, and `evolve/refine/patterns.md` to see what was written.

Never put credentials in memory. If the agent proposes a memory write, it must pass the deny-list and classification rules first.
