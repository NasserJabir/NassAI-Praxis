# Show HN: NassAI-Praxis – A Markdown-first declarative layer for AI coding agents

## What

NassAI-Praxis is a Markdown-first framework that gives AI coding agents persistent project memory, specialized skills, agent roles, personas, evaluation, and human-reviewed evolution. The agent remains the runtime; Praxis is the readable curriculum stored in the project and reviewed through Git.

## Why

We built it to address the practical failure mode where an agent solves each session locally but later work needs its conventions, rejected approaches, and past incidents. The repository includes a historical four-session Laravel + Vue comparison, later matched baseline work, raw evidence packages, and an explicit validation boundary. The controlled sample reported task-specific metrics, but later matched comparisons are inconclusive for a general performance advantage; the repository does not present those metrics as a universal claim.

## How

Try it with `git clone https://github.com/NasserJabir/NassAI-Praxis.git`, read `GETTING_STARTED.md`, and use the recommended project-local adapter path in `INSTALL.md`. The repository includes nine adapter directories, documented security procedures for memory writes, token-budget guidance, an optional diagnostic specification, and contribution templates. Feedback on the knowledge model, adapter ergonomics, evidence design, and Markdown-first trade-offs is welcome.
