# Launch Thread — NassAI-Praxis

## Tweet 1

Your AI coding agent has amnesia. It solves today’s task, then forgets your conventions tomorrow. NassAI-Praxis gives it a readable project memory that survives sessions.

## Tweet 2

The daily cost is familiar: re-explain the architecture, repeat the naming rules, remind the agent which bugs were already rejected, and review the same drift again.

## Tweet 3

Praxis treats Markdown as a project knowledge layer: working, semantic, episodic, and procedural memory, plus skills, agents, personas, evaluation, and evolution.

## Tweet 4

It is not another agent, database, server, or model wrapper. The agent remains the runtime. Praxis is a project curriculum that an adapter can consult when the task requires it.

## Tweet 5

Security comes first. Praxis documents a deny-list procedure that agents and integrations must apply before a memory write; Praxis does not rely on a hidden runtime enforcement service.

## Tweet 6

The repository preserves a controlled Laravel + Vue benchmark across four sessions. It also preserves later matched comparisons and their raw evidence.

## Tweet 7

The historical sample reported task-specific differences. The current canonical results are deliberately narrower: continuity, cross-harness, evolution, and Persona observations exist, while later matched comparisons are inconclusive for a general performance advantage.

## Tweet 8

Before: `Product::create($request->all())`. After: a Form Request validates input and a repository receives `$request->validated()`. Memory preserved the security lesson.
