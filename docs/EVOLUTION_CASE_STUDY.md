# Evolution Case Study

This case study is a controlled, evidence-first record for demonstrating human-governed Praxis evolution. It does not treat an agent suggestion as an automatic skill mutation.

## Observed Controlled Experiment: Evolution 001

Evolution 001 ran in an isolated Praxis fixture using six fresh OpenCode sessions. Three sessions independently recorded the same class of validation-reporting problem from distinct evidence packages. A separate synthesis session derived only candidate artifacts. The project owner explicitly approved the named proposal, after which one session created a **trial-only** skill and a later fresh session read and applied it without modifying it.

| Stage | Result | Knowledge status |
|---|---|---|
| Sessions 1–3 | Three distinct evidence packages yielded `observed` experiences about matching validation claims to their direct scope. | observed |
| Session 4 | A pattern, proposal, and `31/33` candidate evaluation were created without a skill or approval. | candidate |
| Human review | The project owner explicitly approved the exact proposal and trial-skill path. | approved |
| Session 5 | The authorized trial skill was created only after approval. | approved, trial-only |
| Session 6 | A later fresh session read the skill and applied it in a bounded Cross-Harness report without changing the skill or protected knowledge. | observed reuse |

## Promotion Requirements

The proposal must link to original session records, show repeated evidence, include confidence and limitations, pass normal security and conflict checks, and receive human approval. Evolution 001 satisfied these gates **inside its isolated fixture**. The approval did not authorize automatic promotion into Praxis Core or future autonomous mutation.

## Current Status

`observed`. The complete package—protocol, six raw transcripts, three experiences, candidate pattern, proposal, evaluation, explicit human review, trial skill, reuse report, and SHA-256 integrity values—is retained in [`evidence/evolution-001`](../evidence/evolution-001/EVALUATION.md).

> Evolution 001 demonstrates a **human-governed loop**: evidence produced a proposal; a human approval authorized one trial skill; and a later fresh session reused it. It does **not** demonstrate autonomous self-improvement, automatic skill promotion, cross-model behavior, a baseline advantage, or broad real-world coding improvement.
