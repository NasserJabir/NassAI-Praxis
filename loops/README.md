# Loop Engineering

Loop Engineering defines how an agent executes work, evaluates outcomes, learns from experience, and evolves capabilities. The loops are explicit and composable; no claim of autonomous self-learning is made beyond the documented, evidence-based process.

The three loops are:

1. **Execution Loop:** understand, plan, execute, verify, correct, complete.
2. **Learning Loop:** observe, evaluate, reflect, learn, update memory.
3. **Evolution Loop:** evaluate repeated evidence, generalize, propose, validate, promote after human review.
