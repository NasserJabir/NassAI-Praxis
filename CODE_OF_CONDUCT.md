# Code of Conduct

## Our Pledge

We pledge to make participation in the NassAI-Praxis community respectful, constructive, and free from harassment. We welcome contributors regardless of background, identity, experience level, or the coding agent they use.

## Expected Behavior

Contributors are expected to communicate in good faith, critique ideas rather than people, respect project boundaries and review decisions, protect private information, and help maintain an evidence-first discussion culture.

## Unacceptable Behavior

Harassment, discrimination, threats, doxxing, deliberate disclosure of secrets or private data, abusive language, sustained disruption, and misrepresentation of evidence are not acceptable.

## Scope and Enforcement

This Code applies in issues, pull requests, discussions, and other project spaces. Maintainers may remove content, limit participation, or take other proportionate action when this Code is breached.

## Reporting

For a conduct concern, contact the project maintainer privately through the repository owner’s GitHub profile rather than opening a public issue. Do not include credentials, personal data, or security vulnerabilities in a conduct report.

## Attribution

This Code is adapted from the principles of the Contributor Covenant, version 2.1.
