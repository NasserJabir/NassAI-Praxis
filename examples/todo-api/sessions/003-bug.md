# Session 003 — Fix Missing Validation Bug

## Task

Fix a bug where an empty title reached the Todo procedure.

## Error

The first implementation checked only whether the title field existed; whitespace-only values passed through.

## Solution

Normalize and validate the title at the request boundary before invoking the procedure.

## Evaluation

The regression check failed before the correction and passed after it. The solution is generalizable to all string filters and titles.

## Learning

Pattern: request-boundary validation must normalize values before presence checks.
